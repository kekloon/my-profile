# Edmond Wong My Profile - Astro Project

```markdown:README.md
This project is a personal portfolio website built using Astro, React, and Tailwind CSS. It showcases skills, projects, and certifications, and includes interactive elements like a star field and floating images.

## 🚀 Project Structure

Inside the project, you'll find the following folders and files:

```text
/
├── public/
│   └── favicon.svg
├── src/
│   ├── components/

│   │   └── RecentMessages.tsx
│   ├── layouts/

│   └── pages/

```

## 🌟 Features

- **Interactive Star Field**: A 3D star field created using `@react-three/fiber` and `@react-three/drei`.
- **Floating Images**: Animated images that float across the screen.
- **Skills and Projects**: Displays skills with progress bars and a list of projects.
- **Certifications**: Showcases certifications with badges.
- **Message Drop**: Allows users to send messages and displays recent messages with emotion detection.

## 📦 Dependencies

- **Astro**: Static site generator.
- **React**: JavaScript library for building user interfaces.
- **Tailwind CSS**: Utility-first CSS framework.
- **Framer Motion**: Animation library for React.
- **Three.js**: 3D library for creating graphics.
- **Lucide React**: Icon library.
